# 🔬 Data Scientist Portfolio Template

Una plantilla moderna y gratuita para crear tu portfolio como científico de datos. Diseñada especialmente para profesionales del análisis de datos que buscan mostrar sus proyectos de manera profesional y atractiva.

## 1. Características

- 🎨 **Diseño moderno y profesional** con tema oscuro
- 🌍 **Soporte bilingüe** (Español/Inglés)
- 📱 **Totalmente responsive** para todos los dispositivos
- 🚀 **Fácil de personalizar** sin conocimientos avanzados
- 💼 **Secciones especializadas** para científicos de datos
- 🔗 **Links a redes sociales** y repositorios
- ⚡ **Carga rápida** y optimizada

## 2. Tecnologías Utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Estilos modernos con gradientes y animaciones
- **JavaScript** - Funcionalidad de cambio de idioma
- **Font Awesome** - Iconografía profesional
- **Google Fonts** - Tipografía Poppins

## 3. Instalación y Uso

### Opción 1: Descarga Directa
1. Descarga o clona este repositorio
2. Personaliza la información con tus datos
3. Sube los archivos a tu hosting favorito

### Opción 2: Fork del Repositorio
1. Haz fork de este repositorio
2. Clona tu fork localmente
3. Personaliza y sube los cambios


## 4. Personalización

### Información Personal
Edita el archivo `index.html` y reemplaza:
- `[Your Name]` - Tu nombre completo
- `[Your Email]` - Tu correo electrónico
- `[Your GitHub Profile URL]` - URL de tu perfil de GitHub
- `[Your LinkedIn Profile URL]` - URL de tu perfil de LinkedIn
- `[Your education details]` - Detalles de tu educación
- `[A short summary of your interest in data science]` - Resumen sobre ti

### Proyectos
Actualiza las secciones de proyectos con:
- `[Project Title 1/2]` - Títulos de tus proyectos
- `[Brief description of project 1/2]` - Descripciones breves
- `[GitHub link 1/2]` - Enlaces a tus repositorios

### Traducciones
Para modificar las traducciones, edita el archivo `script.js`:
- `englishContent` - Contenido en inglés
- `spanishContent` - Contenido en español

## 5. Personalización Visual

### Colores
Los colores principales están definidos en `style.css`:
- **Primario**: `#008080` (Teal)
- **Secundario**: `#FF6347` (Orange)
- **Fondo**: `#181818` (Dark Grey)
- **Texto**: `#f5f5f5` (Light Grey)

### Fuentes
Actualmente usa **Poppins** de Google Fonts. Para cambiarla:
1. Modifica el link en `index.html`
2. Actualiza `font-family` en `style.css`

## 6. Estructura del Proyecto

